🌍 Travelogue
Travelogue is an Android travel planner and journal app built with Kotlin and Jetpack Compose.

The app helps users organize a trip, plan activities, keep track of places, mark activities as visited, and share places with others.

📱 Current Features
Create a trip
Add trip destination and travel dates
Automatic date formatting
Date validation
View a trip dashboard
Create multiple itinerary activities
Add activity dates, times and notes
Mark activities as planned or visited
Automatically add visited activities to Places
Add multiple places manually
View place details
Track places as "Want to Visit" or "Visited"
Share places using Android's native sharing system
Form validation and user-friendly input formatting
🧭 App Flow
Launch
→ Home
→ Create Trip
→ Trip Dashboard
→ Itinerary
→ Add Activity
→ Places
→ Add Place
→ Place Details
→ Share Place

🌱 Project Status
Milestone 1 is currently under development.

The main application flow is functional, with ongoing work focused on validation, UI improvements, testing, and persistence.

💾 Current Data Storage
Travelogue currently uses an in-memory store to manage activities and places during an app session.

Persistent local storage is planned for a future version.
